# Lichtlabor Sehen

Interaktive Unterrichtsseite zu Lichtquellen, beleuchteten Körpern, dem Sehvorgang und dem Lichtstrahlmodell.

**Einordnung:** Unterrichtsmaterialien → Physik → Optik → Licht und Sehen.

## Öffnen

**[Lichtlabor online öffnen](https://jubitwo.github.io/Lichtlabor-Sehen/)**

| Datei | Zweck |
|---|---|
| [index.html](./index.html) | Interaktive Lernstrecke mit fünf Schritten |
| [docs/README.md](./docs/README.md) | Unterrichtsverlauf, Bedienung und Pflege |

## Lernstrecke

1. **Lichtquellen:** 17 Karten als natürliche Lichtquelle, künstliche Lichtquelle oder beleuchteten Körper einordnen.
2. **Wie sehen wir?** Lampe, Buch, Auge und Wand verschieben; Lichtwege und Sichtbarkeit untersuchen.
3. **Lichtstrahlmodell:** Zeichenregeln kennenlernen und sechs Zeichnungen beurteilen.
4. **Lichtweg zeichnen:** Lichtstrahlen in drei Situationen einzeichnen und überprüfen.
5. **Merksätze:** Begriffe in einem Lückentext sichern.

Der aufklappbare Lehrkraftbereich enthält einen Vorschlag für eine 45-minütige Unterrichtsstunde.

## Lokal starten

Repository herunterladen oder klonen und [index.html](./index.html) in einem aktuellen Browser öffnen. Kein Build und kein Server erforderlich. Schriftarten werden von Google Fonts geladen; ohne Internet nutzt die Seite Ersatzschriftarten.
